HI!

I build practical, open-source software that stays on your device —
**no tracking, no cloud, no accounts**. Most of it solves everyday
problems: a weather app for my town, an EPUB reader, terminal tools,
and lightweight home-server web apps.

## What I'm building

- **Android apps** — privacy-first, with real utility (see my [portfolio](https://adegard.github.io/blog/))
- **Terminal & Termux tools** — software that runs where you already are
- **Web & self-hosted apps** — lightweight PHP/Python tools for the home server
